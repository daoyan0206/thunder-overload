# 雷霆战机：无限超载

用 Game Studio 构建的竖屏自动射击游戏。可以直接在 Game Studio 侧栏试玩，也可打开[离线游戏](export/雷霆战机-无限超载.html)。导出为单文件，不依赖网络。

## 操作
- 手机：按住并拖动战机；第二根手指可点击右下角雷暴，不中断移动。
- 电脑：方向键或 WASD 移动，自动射击；空格释放雷暴，P/Escape 暂停，M 切换音效。
- 标题页点击或按 Enter 出击，死亡后稍等1秒再点击/Enter重开。
- 切出页面自动暂停，回来点击或按 P 继续。

## 内容
- 不设最终关、最终Boss或等级上限；无限指持续生成，不是同时无限实体。
- 击杀和晶体提供经验，自动升级，不打断战斗。
- 主炮散射逐步增加，3级导弹、5级贯穿激光、7级双僚机、9级链式闪电；弹数和射速封顶后伤害仍成长。
- 普通、摆动、追击、重装敌机，精英；三种Boss循环使用扇形、螺旋、瞄准弹幕，按血量阶段增强。
- 护盾、回血、狂暴、磁吸、雷暴能量；雷暴清敌弹并造成全场伤害。
- 击杀攒晶石，永久核心提供下局伤害加成及阶段性额外装甲；最高分、晶石、静音使用当前浏览器本地存储。关闭存储仍可玩，但不能保存；不同浏览器/地址的记录不共享。
- 矢量机械战机、滚动深空、弹幕光效、冲击波、爆炸粒子、连击与技能音效。未使用收费图片生成。
